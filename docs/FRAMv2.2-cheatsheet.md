# F-RAM v2.2 - Cheat Sheet (Working Summary)

**Goal:** Layout- and time-aware retrieval with calibrated widening plus claim-aware coverage. The objective is monotone submodular, so lazy greedy (CELF) delivers near-optimal coverage under a fixed budget.

## Key pieces

- **Embeddings:** Choose `embedding_backend` (`vocab`, `hashing`, or `tfidf`) with `FRAM_EMBEDDING_BACKEND`; ingestion and query flows must share the same backend.
- **Environment:** Pin `scikit-learn` to `1.7.2` (with `joblib>=1.4`) so persisted corpus metadata, ANN indices, and calibration payloads remain compatible across runs.
- **Serving surface:** `/query`, `/memory` (create/control/append/dismiss/search), `/memory/lived/*`, `/observability/*`, `/metrics`, `/time`, `/where`, and `/label` all call the shared `QueryOrchestrator`. Cognitive seeding and durable lived-memory recall are enabled by default; explicit true values for `FRAM_DEV_PROFILE` additionally enable fractal traces unless `FRAM_FRACTAL_ENABLED` is set. False or invalid profile values fail closed.
- **Runtime isolation:** Set `FRAM_STORAGE_ROOT` to keep mutable serving, memory, index, and observability state outside the tracked checkout. The Windows launchers derive a profile-local `.fram/runtimes/fram_v22_starter/storage` path when it is absent so packaged Codex Desktop and ordinary VS Code shells resolve the same physical runtime; they bind to loopback and keep dev/autolog off unless explicitly enabled.
- **ANN backend:** Defaults to scikit-learn; set `FRAM_ANN_BACKEND=faiss` when `faiss-cpu` is available to persist and reuse a FAISS index (falls back automatically when unavailable).
- **Warnings:** Local `pytest` stays noisy; CI can run `make test-warnings` to execute `pytest -W error` over the calibration suite. `pytest.ini` temporarily suppresses the legacy sklearn persistence warning while caches finish self-healing.
- **Slow tests:** Run the fast set with `pytest -m "not slow"`; slow integration tests are marked `@pytest.mark.slow`.
- **Subspace routing:** For cluster k with centroid `p_k` and basis `U_k` (rank `r`): project the query into the local subspace, search locally, and cap ranks in `[6, 12]` (`8` on hot tiers). The orchestrator reorders shards using the projected query before confidence and widening.
- **Confidence features:**
  - `Delta_d_z` (distance shift), `rho_pos` (local density), `mhd` (Mahalanobis ratio), `d_c_z` (centroid distance), and `fresh` (recency decay).
  - Logistic score: `a*Delta_d_z + b*rho_pos + c*mhd + g*d_c_z + h*fresh + d`, scaled by `temperature`.
  - Conformal thresholds `tau1` (no widen) and `tau2` (global fallback) target `alpha1 ~ 1%` and `alpha2 ~ 0.3%` miss rates.
- **Anchors (curvature-aware):** Residual covariance drives anchor steps along top eigenpairs. Candidates clamp steps to the 60th-90th percentile radius. Diversity is enforced via a section/segment repeat penalty (tracked in traces), not a Jaccard term.
- **Coverage (claims, concave):** Typed claims track independence buckets `{doc, layout_block, cluster}`. Coverage uses `Cov(X) = sum_i w_i * (1 - gamma^min(u_i(X), u_max))` with defaults `gamma = 0.6`, `u_max = 3`. Admission cost mixes reads, `lambda_tok` (tokens), and `lambda_rerank` (pairs).
- **Defaults:** `k0 = 32`, `G = 16` (global shortlist), `lambda_tok = 0.002`, `lambda_rerank = 0.05`, `headroom = 0.15`, `default_query_reads = 5`, `cognitive_memory_k = 12`, `cognitive_memory_token_budget = 0` (unlimited), `cognitive_memory_slot_budget = 0` (unlimited), `section_repeat_penalty = 0.7`, `section_penalty_floor = 0.3`.
- **Persisted demo corpus:** `save_corpus_cache` now stamps a `corpus.meta.json` alongside ANN metadata; `QueryOrchestrator.ensure_corpus()` automatically rebuilds vectors/ANN when the local `sklearn` version drifts from the persisted payload, so stale joblib snapshots can't leak into tests.

- **Memory behavior:** Working-memory and cognitive seeds are admitted within the total read budget unless `cognitive_memory_slot_budget <= 0`, which allows memory slots to exceed the read budget. `session_memory_k` controls how many selected chunks are cached for replay in the next call, not how many working-memory entries are injected for this call. Set `FRAM_COGNITIVE_MEMORY_K=0` to disable cognitive seeding.
- **Full-experience invariant:** Cognitive memory is append-only and preserves all experience (no retention pruning or forgetting). `preserve_full_experience` (env `FRAM_PRESERVE_FULL_EXPERIENCE`) locks retention/decay/hard-forgetting knobs off by default.
- **Durable lived memory:** Finalized query/answer experiences persist transactionally in `storage/memory/lived/lived_memory.sqlite3` with full embeddings, citations, per-session parent lineage, rolling session state, and a digest chain. Restarted processes recall those events as `lmem:event:<id>` candidates. See `docs/lived_memory.md`.
- **Higher projection:** Each lived event uses the shared deterministic 6D fractal carrier, an exact recursive lift to 12D by default, and a stored 64-node lifted fractal path. Recall combines full-embedding, event-projection, and lived-state similarity. The derived projection is not identity, consciousness, authorship, or authority evidence.
- **Lived-memory integrity:** `GET /memory/lived/verify` or `python tools/lived_memory.py --root storage/memory/lived verify` recomputes event/state digests and validates every session head. Status, search, and session-state endpoints live under `/memory/lived/*`.
- **Visual-seed canary (evaluation only):** `tools/eval_visual_seed.py` compares path-lossless-ledger-backed raster embeddings with deduplicated lived-event text. It keeps F-RAM text results primary, defaults to privacy-minimal local reports, refuses source/output aliases and mutable resolved model refs, writes no lived memory, and remains `KEEP_OFF` pending explicit human labels and measured lift/false positives. See `docs/evals/visual_seed_canary.md`.
- **Imported seed separation:** Backup episodes without source session/parent markers default to independent root sessions (`--lineage-mode separate`). They remain globally searchable but do not share rolling state unless explicitly resumed. `tools/open_lived_memory_seeds.py` converts legacy mixed imports read-only; separate roots are provenance units, not identity claims.
- **MCP persistence gate:** `fram.query` via MCP is ephemeral by default; enable cognitive episode writes only when `FRAM_MCP_COGNITIVE_WRITE_ENABLED=1` and `persist_cognitive=true`.
- **Append dedupe:** Working-memory appends honor a short dedupe window and an optional `idempotency_key` to ignore retry duplicates (pass the key directly for REST or via MCP metadata).
- **Cross-session recall:** Episodes written on `/query` are eligible for cognitive seeding on later `/query` runs. When they surface, `trace.cognitive_memory.selected` includes `cmem:ep:<id>` and citations include `cmem:ep:<id>:chunkN`.
- **Cognitive memory budget:** `cognitive_memory_token_budget = 0` (env `FRAM_COGNITIVE_MEMORY_TOKEN_BUDGET`) means unlimited; set a positive value to cap admitted memory tokens. `cognitive_memory_slot_budget = 0` (env `FRAM_COGNITIVE_MEMORY_SLOT_BUDGET`) means unlimited memory slots; set a positive value to cap memory entries. See `docs/FRAMv2.2-tuning.md` for the full dial map.
- **Cognitive links:** POST `/memory/link` to connect beliefs/episodes with `supports`, `contradicts`, or `refines`; links are stored in `storage/memory/cognitive/links.jsonl` and surface in `/observability/memory/summary`.
- **Constraint memory (v0):** POST `/memory/constraint` to store scoped constraints (`global/personal/session`) as derived layers; enforcement appears in `trace.constraint_memory`.
- **Memory capsule (no-ceiling, write-through):** Set `FRAM_MEMORY_CAPSULE_ENABLED=1` to append a Memory Capsule on each `/query`. Capsules live under `storage/memory/capsules/` and include raw transcript (plus working-memory session entries when present), per-turn embeddings, a fractal trace stack, and the remembering definition. Retrieval now feeds `/query` when `FRAM_MEMORY_CAPSULE_RETRIEVAL_ENABLED=1`, using per-turn embedding cosine with lexical fallback (`FRAM_MEMORY_CAPSULE_RETRIEVAL_K`, `FRAM_MEMORY_CAPSULE_RETRIEVAL_TURNS_PER_CAPSULE`, `FRAM_MEMORY_CAPSULE_RETRIEVAL_HALF_LIFE_HOURS`). `tools/experiment_log.py --write-capsule` can snapshot an experiment run into a capsule.
- **Continuity witness (feature gated):** Set `FRAM_CONTINUITY_WITNESS_ENABLED=1` to append a sanitized, digest-verified decision sidecar after query/memory/archive finalization. It is never used by retrieval or ranking. Inspect the explicit available/unknown/stale/corrupt/tampered envelope at `GET /observability/continuity/witness`.
- **Ecological Strata ledger (explicit only):** `fram_serving/ecological_strata.py` persists the separate Offer -> Mirror -> Correct -> Consent -> Bind -> Return protocol with refusal/revocation and no identity collapse. It has no automatic query hook or HTTP write route; operate it explicitly with `python tools/ecological_strata_ledger.py`.
- **Capsule cadence (optional):** `COGMEM_CAPSULE_EVERY_N` writes snapshots every Nth turn, while `COGMEM_CAPSULE_TAGS` forces snapshots for tagged decisions/commitments.
- **Autowire ack log:** `tools/autowire_turn.py` appends an ack line to `logs/fram_write_ack.jsonl`. Set `COGMEM_ECHO_ACK=1` to print the ack JSON.

- **Fractal traces (feature gated):** When `FRAM_FRACTAL_ENABLED=1`, cognitive episodes spawn deterministic 6D trace lines stored under `storage/memory/fractal/` (`FractalTraceStore`). `/query` blends cosine and soft-DTW scores, emits replay nodes with chunk refs, and observability captures rankings/backfills (`/observability/memory/fractal/ping`). `/memory/fractal_trace` returns full bundles for inspection. Cognitive ranking influence is gated by `FRAM_FRACTAL_INFLUENCE=1` (default off) with `FRAM_FRACTAL_INFLUENCE_ALPHA` (default 0.05). Quaternion + lambda alignment metrics are now reported for evaluation; optional ranking influence is gated by `FRAM_FRACTAL_QUAT_INFLUENCE=1` (default off) with `FRAM_FRACTAL_QUAT_WEIGHT` (default 0.2) and `FRAM_FRACTAL_QUAT_USE_LAMBDA` (default true). Tune via FRAM_FRACTAL_BLEND_ALPHA (default 0.4) and FRAM_FRACTAL_DOWNSAMPLE_TARGET (default 256); traces record a seed_hash for provenance.
- **Phase D (feature gated):** `/rank/relevance` optionally returns `phase_d_scores` plus `phase_d_diagnostics` when `phase_d.enabled` is on; enabling `phase_d.debug_observability` also adds `phase_d` diagnostics (`alpha_t`, `alpha_color`, `quat_avg`) to `/observability/recall_report` alongside fractal recall stats. Memory bridge is gated separately via `phase_d.enable_memory_bridge` so cognitive recall ranking can opt into blended scores; `/observability/phase_d_memory` and `/observability/cognitive_summary` provide tiny HTML/JSON views of recent bridge events and cognitive selections.
- **Phase D observability quick check:** `python tools/phase_d_memory_summary.py --json` or `GET /observability/recall_report` expose `phase_d_memory.stats` (events, scored totals/avg, alpha/quaternion means, color counts, missing_alpha). Expect `missing_alpha=True` if debug is off or scores lacked diagnostics; turn on `phase_d.debug_observability` to surface `alpha_*` when available.

- **Cognitive memory search details:** Ranking uses hashing-vector cosine when vectors are available, otherwise token-overlap fallback. Episode scores blend a query-only recall boost (`FRAM_COGNITIVE_MEMORY_QUERY_RECALL_WEIGHT`, default 0.2) to reduce length penalties. Scores are weighted by recency with a configurable half-life and packed into a token budget using score, recency, and score-per-token; dismissed items are skipped during cooldown. Episode vectors now feed an ANN index (sklearn default; FAISS when `FRAM_ANN_BACKEND=faiss`), and the ANN bridge is enabled by default (`FRAM_COGNITIVE_ANN_TOP_K=8`).
- **Semantic memory embeddings (optional):** Set `FRAM_COGNITIVE_MEMORY_EMBEDDING_BACKEND=semantic` and `FRAM_COGNITIVE_MEMORY_SEMANTIC_MODEL=all-MiniLM-L6-v2` (requires `sentence-transformers`), then run `python tools/backfill_cognitive_embeddings.py` once to populate vectors for existing episodes.

- **Embedder/backend alignment:** If a persisted corpus' vector dimension differs from `len(vocab)`, serving coerces a hashing vectorizer and labels the backend as `hashing` to keep queries consistent; consider rebuilding or persisting the TF‑IDF embedder to avoid ambiguity.

- **Bootstrap helper:** Run `python tools/bootstrap_memory.py --window 5` at session start to pull recent cognitive episodes/beliefs (falls back to JSONL when the server is offline).
- **Doc + calibration refresh:** `make refresh-docs` (runs recent-docs scan, doc ingest, demo ingest, calibration lint/status). For a no-op preview use `python tools/refresh_docs_calibration.py --dry-run`.
- **Calibration refresh automation:** `make refresh-calibration` (harvest -> backfill -> slice -> fit -> lint -> status). Use `python tools/refresh_calibration.py --dry-run` to preview commands.
- **Close-out guard:** Run `python tools/closeout_guard.py` before ending a session; it verifies the final turn is logged and `docs/CODEX_DIARY.md` + `docs/F-RAM-roadmap.md` are updated.
- **Diagnostics:** `python tools/cognitive_memory_summary.py` summarises memory search logs under `storage/observability/memory_cognitive.jsonl`. A rolling snapshot of search telemetry lives at `storage/observability/memory_search.json`.
- **Observability UI:** `GET /ui/observability` for a quick browser view of metrics, traces, recall, and memory summaries.
- **Experiments UI:** `GET /ui/experiments` for filtered experiment and decision review plus digest preview.
- **Capsule inspector:** `python tools/inspect_capsule.py storage/memory/capsules/<capsule>.json` prints a read-only summary of turns, roles, embeddings, and trace-stack alignment.
- **Capsule falsification:** `python tools/falsify_capsule.py storage/memory/capsules/<capsule>.json --json` applies corruption variants (shuffle, targeted drop, random drop, role-noise, trace-noise) and reports alignment drops.
- **Defaults snapshot:** `python tools/print_fram_defaults.py --from-env --diff --out artifacts/observability/fram_defaults.json` captures current config overrides for audits.
- **Ablation:** python tools/fractal_ablation.py --limit 20 compares cosine / soft / blend rankings using storage/observability/memory_fractal.jsonl.
- **Falsification harness:** python scripts/fractal_falsification.py writes correlation + top-k stats to storage/observability/fractal_falsification.json. Use `--seeds 0,1,2` to sweep and emit an aggregate section. If multi-system sweeps time out, run per-system and merge with `--merge path1.json,path2.json --out storage/observability/fractal_falsification.json`.
- **Conversation memory eval:** python scripts/conversation_memory_eval.py evaluates paraphrase recall (semantic vs lexical) and writes to `storage/observability/conversation_memory_eval.json`; add `--details --details-topk 5` to emit per-probe rank dumps for failure analysis. Add `--kinds episode` to restrict the pool to episodic memories when testing fractal influence. Use `--fractal-alpha-low-lex` + `--fractal-low-lex-threshold` for the eval-only low-lex gate (quoted phrases are ignored when computing overlap), add `--fractal-low-lex-overlap-mode answer` to compare only the episode answer text, or `--fractal-low-lex-sim-threshold` to gate on cosine similarity. Use `--fractal-soft-dtw-gamma`, `--fractal-soft-dtw-band`, and `--fractal-soft-dtw-score-mode` (inverse/exp) to tune soft-DTW trace scoring, `--fractal-cosine-mode` to pick the cosine target (composite vs centroid vs delta vs turn_hist vs lag_dist vs radius_hist vs curvature_hist), `--fractal-trace-norm-mode` (minmax/percentile) to change score normalization, `--fractal-query-path-mode` (synthetic/ifs) to switch query path construction, and `--fractal-low-lex-query-path-mode` to swap query paths only when the low-lex gate fires.
- **Production selection gate:** `python -m scripts.production_memory_eval` exercises actual `run_query` memory selection on verified offline copies. One-item smoke is the default; full paired coverage, finite metrics and a declared shared evaluation clock are required for activation evidence. See [production memory gate](production_memory_gate.md). Candidate-reranking results do not establish production parity. Influence-enabled trace scoring excludes unbound episode IDs from normalization and ranking while preserving their files and influence-off replay.
- **Two-pass eval harness:** `python scripts/run_fractal_two_pass_eval.py` runs probe and low-lex passes with different query-path modes (defaults: synthetic for probe, IFS for low-lex), merges the results, and emits a combined report + auto-flip recommendation.
- **Live memory probes:** python scripts/conversation_memory_eval.py --live uses `fram_eval/data/conversation_memory_live_probes.jsonl` (supports `match_episode_id` to disambiguate) and writes to `storage/observability/conversation_memory_eval_live.json`.
- **Fractal ablation (memory):** add `--modes semantic,lexical,fractal` plus `--pool-multiplier`/`--fractal-alpha`/`--fractal-trace-k` to compare classic vs fractal re-ranking. Use `--fractal-alpha-low-lex` + `--fractal-low-lex-threshold` for eval-only gating.
- **Memory shadow eval:** python scripts/memory_shadow_eval.py --live writes to `storage/observability/memory_shadow_eval_live.json` and reports embedding-shift deltas after memory injection; add `--kinds episode` to keep the pool episodic. Low-lex gate flags, soft-DTW tuning flags, and cosine-mode flags match the conversation eval CLI.
- **Fractal trace diagnostics:** python scripts/fractal_trace_probe_eval.py dumps candidate distributions plus expected/top percentiles for trace metrics. Start with `--dataset fram_eval/data/conversation_memory_live_paraphrase_hard_micro.jsonl --fields probe_low_lex --kinds episode` and the same fractal flags you used for the eval run (including `--fractal-query-path-mode`).
- **Fractal trace ablation report:** python scripts/fractal_trace_ablation_report.py --dataset fram_eval/data/conversation_memory_live_paraphrase_hard_micro_v3.jsonl writes per-probe expected vs top trace scores plus cosine/soft-DTW component deltas (use `--fractal-query-path-mode ifs` for IFS-conditioned paths).
- **Fractal trace identity check:** python scripts/fractal_trace_identity_check.py scores each episode using its stored embedding against trace candidates to confirm self-match in isolation; outputs a per-episode rank/score report. Add `--raw-vectors` to skip normalization and `--query-path-mode ifs` to build query paths using each trace's IFS seeds.
- **Fractal trace alignment probe:** python scripts/fractal_trace_alignment_probe.py compares raw vs normalized embeddings against stored traces (seed hash + cosine/soft-DTW deltas).
- **Fractal auto-flip:** python scripts/fractal_autoflip.py compares conversation+shadow evals and emits a KEEP_OFF/ENABLE recommendation in `storage/observability/fractal_autoflip.json` (print `FRAM_FRACTAL_INFLUENCE=1/0` with `--print-env`). Defaults require top1 lift >= 0.02 on probe + low-lex, and allow shadow avg_delta to be up to 0.01 below baseline; see `docs/FRAMv2.2-tuning.md`.
- **One-command eval + report:** python scripts/run_fractal_eval_report.py --live --dataset fram_eval/data/conversation_memory_live_probes.jsonl --label live_probes writes eval JSONs plus a markdown report to `artifacts/observability/`.
- **Autopilot protocol:** council operating rules and pause conditions live in `docs/AUTOPILOT_PROTOCOL.md`.

## Calibration workflow

1. Harvest queries: `python scripts/harvest_calibration.py --queries scripts/calibration_prompts/layout_anchor_queries.txt --quiet --json-out storage/observability/harvest_run.json`.
2. Maintain metadata: `python tools/calibration_backfill.py --log storage/observability/calibration.jsonl --backup storage/observability/calibration.pre_filter.jsonl --default-domain general --default-task qa --default-budget 3 --infer-domain --overwrite-domain --infer-task --overwrite-task`.
3. Slice by domain/task when fitting: `python tools/calibration_filter.py --domain roadmap --include-records` (swap `--task diary`, etc.).
4. Fit payloads: `python scripts/calibrate_confidence.py --log storage/observability/calibration_<slice>.jsonl --out storage/index/demo_corpus/calibration_<slice>.json --lint`.
5. Sanity-check the results: the `--lint` flag runs `tools/calibration_lint.py` for the produced payload; rerun manually as needed with `python tools/calibration_lint.py storage/index/demo_corpus/calibration_<slice>.json --strict` when you need tight bounds (or omit `--strict` for softer checks); use `python tools/calibration_status.py --json` to confirm domain/task files line up.

The orchestrator (`fram_core/pipeline.py`) loads `calibration_<domain>.json` and `calibration_task_<task>.json` at runtime, falling back to `calibration.json`, then to the config defaults. Domain/task overrides still apply after loading payloads (for example, section penalties and read budgets).

`/query` accepts optional `domain`, `task`, and `version_id` (defaults from `FRAM_DEFAULT_DOMAIN` / `FRAM_DEFAULT_TASK`). Traces log `source`, taus, and temperature so dashboards reflect the active payload.

- Calls without explicit metadata are normalised through `FRAMConfig.default_domain/default_task`; if the specialised payload is missing, the orchestrator records `source="global"` and applies the corpus-wide calibration instead of the raw defaults.

### New serving helper
- `GET /calibration` returns the default domain/task, precedence order (`task -> domain -> global -> default`), the loaded global payload, and active domain/task payload summaries (taus, temperature, logistic coefficient keys). Use this after fitting to confirm the server sees the refreshed artifacts.

### Observability
- `/metrics` shows `reliability.by_domain`, `reliability.by_task`, and `latest` entries with calibration context.
- Label endpoint (`POST /label`) and decision logs reuse the stored taus/domain/task metadata to keep the live reliability tracker aligned with serving behavior.

Run `fram-ingest` to prebuild demo corpus assets in `storage/` before serving.
Use this sheet as a fast reference; see `docs/FRAMv2.2-SPEC.md` for the full spec and `docs/Architecture.md` for module responsibilities.







## Version lattice / as-of (update)
- Manifest: `storage/index/<corpus>/versions.jsonl` (version_id, parent_id, timestamp, diff).
- All shards (docs/tables, session replay, cognitive, ANN bridge, connectors, injected memory) carry `version_id`.
- As-of(T) filters shortlist/coverage/replay/memory/connector; traces log `as_of_filter` {as_of, active_nodes, dropped_candidates}; responses include `delta_snippets` from lattice diffs when serving older snapshots.
